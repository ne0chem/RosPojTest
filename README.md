# React: каркас сайта

Сайт РОСПОЖТЕСТ на React, React Router DOM и Vite.

## Публикация на Vercel

1. Загрузите проект в репозиторий GitHub, GitLab или Bitbucket, включая `public/`, `package-lock.json` и `vercel.json`.
2. В Vercel выберите **Add New → Project** и импортируйте репозиторий.
3. В **Root Directory** укажите каталог проекта, в котором находится `package.json` (корень репозитория, если загружен этот проект целиком).
4. Нажмите **Deploy**. Настройки уже заданы в `vercel.json`: Vite, установка `npm ci`, сборка `npm run build`, результат `dist`.

Переменные окружения для текущей версии не требуются. После подключения репозитория новые изменения в основной ветке будут автоматически публиковаться.

Маршрутизация SPA настроена по [документации Vercel](https://vercel.com/docs/frameworks/frontend/vite): прямые переходы и обновление `/services`, `/contacts` и других страниц возвращают приложение. Якоря категорий (`/services#testing`) обрабатываются в браузере.

Альтернативный способ из каталога проекта:

```sh
npx vercel
npx vercel --prod
```

Первая команда подключает проект к аккаунту и создаёт предварительную публикацию, вторая публикует production-версию.

Форма заявки сейчас открывает почтовую программу через `mailto:`. Серверной отправки писем в проекте нет.

## Запуск

```sh
npm install
npm start
```

Откройте адрес, который Vite выведет в терминале (обычно http://localhost:5173).

## Команды

- `npm start` — сервер разработки.
- `npm run build` — сборка в `dist`.
- `npm run preview` — локальный просмотр сборки.

## Структура

- `src/components/` — Header и Footer.
- `src/layouts/Layout.jsx` — общая оболочка страниц.
- `src/pages/` — Главная, Услуги, О нас, Контакты и страница 404.
- `src/App.jsx` — маршруты.
- `src/styles.css` — общие стили и адаптивная навигация.

При размещении сборки настройте сервер так, чтобы адреса страниц
(`/services`, `/about`, `/contacts`) возвращали `index.html`.
